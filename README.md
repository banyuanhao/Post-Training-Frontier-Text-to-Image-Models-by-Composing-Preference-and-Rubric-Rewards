# How to Post-Train Text-to-Image Models

GitHub Pages project page for **Post-Training Frontier Text-to-Image Models by Composing Preference and Rubric Rewards**.

The page is authored in `src/paper.mdx` and built with Astro.

## Local preview

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site is emitted to `dist/`. GitHub Actions deploys the site from the `main` branch when GitHub Pages is configured to use Actions.
